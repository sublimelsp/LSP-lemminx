Breaking changes:

- The key used to override LSP-lemminx settings in project settings has changed from `LemMinX` to `LSP-lemminx`.
  If you use project-specific overrides for LSP-lemminx, you have to rename the key for them to apply:

  Before:

  ```jsonc
  {
      "settings": {
          "LSP": {
              "LemMinX": {
                  // ...
              }
          }
      }
  }
  ```

  After:

  ```jsonc
  {
      "settings": {
          "LSP": {
              "LSP-lemminx": {
                  // ...
              }
          }
      }
  }
  ```
